# 이승연 영상 포트폴리오

[Dennis Snellenberg](https://dennissnellenberg.com/)의 큰 타이포그래피, 화면 전환, 곡선 메뉴, 마우스 상호작용을 참고해 구성한 반응형 정적 사이트입니다. 실제 작품은 단편영화 〈각질〉 한 편이며, 미공개 작품·수상 이력·연락처를 임의로 추가하지 않았습니다.

## 생성과 미리보기

저장소 루트에서 Node.js로 HTML을 생성한 다음 정적 서버를 실행합니다. npm 패키지 설치는 필요하지 않습니다.

```sh
node portfolio/tools/build.mjs
python3 -m http.server 4173 --bind 127.0.0.1 --directory portfolio/dist
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 생성된 HTML도 Git에 포함합니다. 배포 워크플로는 HTML 생성기를 실행하지 않고, 저장소의 `dist/` 파일을 그대로 게시합니다.

## 화면 구성

| 경로            | 내용                                                                    |
| --------------- | ----------------------------------------------------------------------- |
| `/`             | 영화 스틸을 배경으로 한 첫 화면, 움직이는 타이포그래피, 소개, 대표 작품 |
| `/work/`        | 작품 목록·이미지 보기, All / Film / Music video 필터                    |
| `/work/gakjil/` | 〈각질〉 정보, 공식 썸네일·GIF, 장면 갤러리, YouTube 링크               |
| `/about/`       | 이름, 서울예술대학교 재학 정보, 영화·뮤직비디오에 대한 관심             |
| `/contact/`     | 연락처 준비 안내, 문의 내용 작성·복사                                   |
| `/archive/`     | 공개 작품 한 편의 필모그래피                                            |
| `/styleguide/`  | 색상·서체·버튼·영상 미리보기 확인 화면                                  |
| `/404.html`     | 없는 페이지 안내와 홈 링크                                              |

위 경로는 로컬 미리보기 기준입니다. GitHub Pages에서는 `/lsy_pp/` 아래에 배치됩니다. 404 화면의 기준 경로는 생성기의 `<base href="/lsy_pp/">`로 지정되어 있으므로 저장소 경로를 바꾸면 함께 수정해야 합니다.

작품이 없는 Music video 필터는 빈 상태를 표시합니다. 작은 화면에서는 작품을 이미지 카드로 보여주며 목록·이미지 전환 버튼은 숨깁니다.

## 수정할 곳

- `tools/build.mjs`: 페이지 구성, 공통 헤더·푸터, 이름·소개·작품 정보, 링크. HTML을 바꿀 때는 이 파일을 수정한 후 생성 명령을 실행합니다.
- `dist/styles/site.css`: 색상, 서체, 배치, 반응형 화면과 CSS 애니메이션.
- `dist/scripts/site.js`: 메뉴, 페이지 전환, GIF, 작품 필터·보기 방식, 문의 내용 복사, 서울 시계.
- `dist/assets/`: 보존한 원본 GIF·공식 YouTube 썸네일과 아이콘.
- `dist/assets/stills/`: 기존 GIF에서 추출한 다섯 장의 영화 스틸. 출처와 시점은 [ASSET-SOURCE.md](ASSET-SOURCE.md)를 참고합니다.

영문 이름과 공개 연락처는 확인 전이라 넣지 않았습니다. 첫 화면과 소개의 인물 이미지는 감독의 프로필 사진이 아니라 〈각질〉 속 배우들이 등장하는 영화 장면입니다.

## 영상 미리보기

영상 카드에는 공식 YouTube 썸네일(`dist/assets/youtube-thumbnail.jpg`, 1280×720)을 자르지 않고 전체 표시합니다. 마우스를 올리면 〈각질〉 03:32–03:39의 7초 GIF가 반복 재생되고, 마우스를 떼면 썸네일로 돌아옵니다. 썸네일·GIF를 클릭하면 YouTube 전체 영상이 새 탭으로 열립니다. 이미지 위에 `Watch film` 문구는 표시하지 않습니다.

모바일과 키보드 사용자는 이미지 아래의 미리보기 재생/정지 버튼을 사용할 수 있습니다. 작품 제목·작품 소개 링크는 사이트 안의 상세 페이지로 이동합니다. 넓은 화면의 작품 목록에 마우스를 올리면 포인터를 따라가는 별도 GIF 미리보기도 표시됩니다.

GIF는 720×311, 12fps, 84프레임, 약 5.35 MB입니다. 기존 GIF와 YouTube 썸네일 파일은 교체하거나 다시 인코딩하지 않았습니다. 추출 스틸은 파일 자체에 크롭·확대를 적용하지 않았지만, 첫 화면과 소개 등에서는 화면 배치에 맞춰 CSS로 일부 영역을 보여줍니다.

## 움직임과 접근성

- 첫 홈 방문의 인사말과 내부 페이지 이동에 곡선 화면 전환을 사용합니다.
- 메뉴는 옆에서 펼쳐지며, Escape·닫기 버튼·메뉴 바깥 클릭으로 닫을 수 있습니다.
- 큰 글자의 가로 흐름, 스크롤 등장, 이미지 패럴랙스, 푸터 곡선, 마우스를 따라 움직이는 버튼을 적용했습니다.
- 운영체제의 `동작 줄이기` 설정에서는 화면 전환·자동 움직임·포인터 미리보기·GIF 자동 재생을 생략합니다. 별도 버튼으로 GIF를 직접 재생할 수 있습니다.
- JavaScript 없이도 페이지 내용, 기본 메뉴, 정지 썸네일과 영상 링크를 사용할 수 있습니다. 필터·보기 전환·미리보기 버튼은 숨기며 문의 복사 버튼은 비활성화합니다.

## 문의 양식

공개 연락처는 준비 중입니다. 이 양식은 이름·이메일·소속·프로젝트·메시지를 정리해 클립보드에 복사하며, 서버나 이메일로 전송하지 않습니다. 자동 복사를 사용할 수 없으면 직접 선택해 복사할 수 있는 텍스트 영역을 표시합니다. 실제 연락처가 확인되면 안내 문구와 전송 동작을 별도로 연결해야 합니다.

## 게시

[공개 사이트 주소](https://whiskend.github.io/lsy_pp/)는 기존 GitHub Pages 설정을 사용합니다.

HTML 수정 후 생성기를 실행해 `dist/` 결과물까지 커밋해야 합니다. `main` 브랜치의 `portfolio/dist/` 파일을 GitHub에 올리면 기존 `.github/workflows/deploy-pages.yml`이 자동 배포합니다. 생성기나 문서만 수정하고 `dist/`를 바꾸지 않으면 자동 배포는 실행되지 않습니다.

배포 상태는 저장소의 [Actions](https://github.com/whiskend/lsy_pp/actions/workflows/deploy-pages.yml)에서 확인합니다. 필요한 경우 같은 화면의 `Run workflow`로 수동 재배포할 수 있습니다.
