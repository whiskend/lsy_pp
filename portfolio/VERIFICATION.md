## 기능 저하 시 동작

- 원본 페이지에서 스크립트 태그를 제거한 별도 검증용 Contact 페이지로 기본 메뉴 표시와 비활성 제출 버튼을 확인했다. 기본 Work 링크가 정상 페이지로 연결됐다. 이는 운영체제나 브라우저 설정 전체를 변경한 검사가 아니다.
- `matchMedia`의 동작 줄이기 응답을 활성화한 별도 검증용 페이지에서 초기 커튼 생략, 이름 이동 정지, 모든 소개 내용 표시, 마우스 GIF 자동 재생 억제, 명시적인 수동 재생을 확인했다. CSS의 실제 운영체제 미디어 쿼리는 소스 점검으로 확인했다.
- 클립보드 거부 시 수동 복사 대체 경로는 소스에서 확인했으며, 브라우저 권한 거부를 강제로 발생시키지는 않았다.

## 콘텐츠 범위

공개 작품은 〈각질〉 한 편이다. 원본 사이트의 프로젝트 수·고객·수상·연락처·인물 사진을 복사하지 않았다. 연락처가 아직 없으므로 Contact는 준비 중 안내와 문의 초안 복사를 제공한다. 본인 사진 대신 영화 스틸을 사용하며 작품명으로 표시했다.

이 기록은 로컬 실행 점검 결과다. 실제 GitHub Pages 배포 성공 여부와 게시 파일 일치는 배포 작업의 Actions 결과 및 공개 URL 응답으로 별도 확인한다.
